# Headphones Webpage Project

## Project Overview

This project involves building a fully functional and responsive webpage from scratch using **HTML** and **CSS**, with a strong emphasis on **accessibility**, **responsive design**, and **pixel-perfect implementation** based on a provided Figma design.

The goal is to recreate the designer's layout accurately and ensure smooth behavior across desktop and mobile screen sizes.

---

## Figma Access Instructions

To get started with design referencing:

1. **Create a Figma account** if you do not already have one.
2. Open the provided Figma project link.
3. Click **“Duplicate to your Drafts”** to gain full access to design layers, measurements, spacing, and component details.

> If you experience font issues, download and install the fonts used in the project:
>
> * `Source Sans Pro`
> * `Spin-Cycle-OT`

Some spacing or size values may appear in **float numbers** — rounding them to the nearest whole number is acceptable.

---

## Interaction Guidelines

To meet design expectations, implement the following interaction details:

| Element                        | Behavior                             |
| ------------------------------ | ------------------------------------ |
| **Screen width 480px or less** | Layout must switch to mobile version |
| **Links (hover/active)**       | `#FF6565`                            |
| **Buttons (hover/active)**     | `opacity: 0.9`                       |
| **Content max width**          | `1000px`, centered on page           |

Ensure responsiveness using **media queries** and proper **flexbox/grid layout** patterns.
